# 1. Playwright Test Agents - Installation

**Pre-Check**
1. ✅ VS Code version (> `1.105.0 `) -> Update if required
2. ✅ Check playwright version - good to have it latest
   
```sh
npx playwright --version # Returns current version
npm view playwright version # Returns latest version
```
3. ✅ Update playwright (recommended)

```sh
npm install -D @playwright/test@latest
npx playwright install
```

**Installation Steps**
1. Run `npx playwright init-agents --loop=vscode`
2. Check the generated files
3. Done !🎉


**Explain command** 
`npx playwright init-agents --loop=vscode`
npx → Runs a Node.js package command without installing it globally.
playwright → Runs the Playwright CLI.
init-agents → Initializes Playwright's AI testing agents.
--loop=vscode → Configures those agents specifically for the VS Code agentic workflow.
